# 🚀 Bootcamp Itaú - Java com Inteligência Artificial (DIO)

Repositório criado para armazenar os exercícios, desafios de código e projetos desenvolvidos durante o **Bootcamp Itaú - Java com Inteligência Artificial**, realizado na plataforma da **DIO (Digital Innovation One)**.

---

## 📝 Sobre o Bootcamp

O bootcamp aborda desde os fundamentos da linguagem Java até o desenvolvimento avançado com **Spring Boot** e integração de **IA Generativa** em aplicações, incluindo o desenvolvimento de APIs e desafios práticos voltados para o mercado financeiro e de tecnologia.

---

## 📁 Estrutura do Repositório

### 📌 Módulo 1: Fundamentos da Linguagem de Programação Java (`src/modulo1`)
- **`Modulo1Exercicio1.java`**: Cálculo de idade com base no ano de nascimento.
- **`Modulo1Exercicio2.java`**: Cálculo da área de um quadrado.
- **`Modulo1Exercicio3.java`**: Cálculo da área de um retângulo.
- **`Modulo1Exercicio4.java`**: Cálculo da diferença de idade entre duas pessoas.

---

### 📌 Módulo 2: Estruturas de Controle em Java (`src/modulo2`)
- **`Exercicio1.java`**: Gerador de tabuada personalizada.
- **`Exercicio2.java`**: Calculadora de IMC (Índice de Massa Corporal) com classificações.
- **`Exercicio3.java`**: Exibição de números pares ou ímpares em intervalo decrescente.
- **`Exercicio4.java`**: Verificação de divisibilidade e múltiplos até condição de parada.

---
